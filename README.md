# INGSTYLE

Telegram-бот для ежедневного учёта настроения, часов работы/учёбы и сна.  
Данные хранятся локально в SQLite. Бот показывает статистику, инсайты и графики.

## Возможности

- Запись за день в 4 шага: настроение → работа → сон → комментарий (по желанию)
- Статистика за неделю и месяц
- Персональные инсайты по вашим данным
- График за последние 7 дней
- История записей и ежедневное напоминание


**2. Установите зависимости:**

```bash
pip install -r requirements.txt
```

**3. Задайте токен бота** через переменную `BOT_TOKEN`

## Запуск

```bash
python bot.py
```

При успешном старте в консоли появится: `Бот запущен...`

База данных `tracker.db` создаётся автоматически при первом запуске.


## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и краткая инструкция |
| `/add` | Записать данные за сегодня |
| `/stats` | Статистика: неделя, месяц, инсайты, график |
| `/history` | Последние 7 записей |
| `/settings` | Время ежедневного напоминания (ЧЧ:ММ) |
| `/clear` | Удалить все записи (с подтверждением) |
| `/help` | Справка по командам |

Внизу чата также доступны кнопки: **➕ Записать день**, **📊 Статистика**, **📋 История**, **⚙️ Настройки**.

## Структура проекта

```
INGSTYLE/
├── bot.py           # Telegram-бот, диалоги, напоминания
├── analyzer.py      # Статистика, инсайты, графики
├── db_handler.py    # Работа с SQLite
├── schema.sql       # Схема базы данных
├── test_data.sql    # Примеры записей для тестов
└── requirements.txt # Зависимости Python
```
